Programs ask for documentation to substantiate a claim. The required types vary by program; common ones are `INVOICE_EQUIPMENT`, `INVOICE_INSTALL`, `PERMIT`, `PHOTO_INSTALL`, `PHOTO_NAMEPLATE`, and `PHOTO_METER`. You don't have to hold them all: Leap Connect collects any types you haven't claimed under **Data Preferences** from the customer, so claim only what you can reliably supply.

## Uploading a file

File bytes never pass through the Applications API. You upload them directly to storage using a pre-authorized URL, the same pattern as an [S3 pre-signed `PUT`](https://docs.aws.amazon.com/AmazonS3/latest/userguide/PresignedUrlUploadObject.html). Only the two calls around that upload are Leap endpoints; your API key authorizes both.

<Steps>
<Step title="Request an upload URL">
  `POST /applications/attachments` with the `attachment_type`, `filename`, and `contentType`. You get back a short-lived **`uploadUrl`** and a **`path`**. Leap prefixes your filename with a unique ID, so two `invoice.pdf`s never collide.

  ```bash
  curl -X POST "https://api.incentives.leap.energy/alpha/applications/attachments?application_id=123" \
    -H "x-api-key: leap_live_your_api_key_here" \
    -H "Content-Type: application/json" \
    -d '{ "attachment_type": "INVOICE_EQUIPMENT", "filename": "invoice.pdf", "contentType": "application/pdf" }'
  # → { "uploadUrl": "https://storage.example.com/attachments/app-123/1a2b3c4d-invoice.pdf?token=...",
  #     "path": "app-123/1a2b3c4d-invoice.pdf" }
  ```
</Step>

<Step title="Upload the file">
  `PUT` the raw bytes to that `uploadUrl` with the file's `Content-Type`. The request goes directly to storage, needs no API key, and returns `200 OK` with an empty body.

  ```bash
  curl -X PUT "$uploadUrl" \
    -H "Content-Type: application/pdf" \
    --data-binary @invoice.pdf
  ```
</Step>

<Step title="Commit">
  `POST /applications/attachments/commit` with the same `attachment_type` and the `path` from step 1. This records the attachment on the application.

  ```bash
  curl -X POST "https://api.incentives.leap.energy/alpha/applications/attachments/commit?application_id=123" \
    -H "x-api-key: leap_live_your_api_key_here" \
    -H "Content-Type: application/json" \
    -d '{ "attachment_type": "INVOICE_EQUIPMENT", "path": "app-123/1a2b3c4d-invoice.pdf" }'
  ```
</Step>
</Steps>

To read a file back, call **Download attachment** for a signed URL, valid for one hour.

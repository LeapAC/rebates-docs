---
title: Applications
description: Create, track, and attach documentation to rebate applications.
---

<Info>
  **Base URL:** `https://api.incentives.leap.energy/alpha`

  **Authentication:** send your Leap API key in the `x-api-key` header —
  `x-api-key: leap_live_...`.
</Info>

Applications represent rebate submissions you track through processing. Search
and update them, and manage supporting **Attachments** (invoices, permits,
photos) via the two-step upload → commit flow.

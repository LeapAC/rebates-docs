---
title: Devices
description: Search the device catalog and a program's approved-device list.
---

<Info>
  **Base URL:** `https://api.leap.energy` (production) · `https://api.staging.leap.energy` (staging)

  **Authentication:** send your Leap API key as a Bearer token —
  `Authorization: Bearer <api-key>`.
</Info>

Use device search to find catalog entries to look up incentives against, and a
program's approved-device list to see which devices qualify for that program.

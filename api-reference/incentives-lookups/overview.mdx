---
title: Incentives Lookups
description: Check device- and customer-level incentive eligibility through the Leap API Gateway.
---

Incentive lookups run against the Leap API Gateway.

<Info>
  **Base URL:** `https://api.leap.energy` (production) · `https://api.staging.leap.energy` (staging)

  **Authentication:** send your Leap API key as a Bearer token —
  `Authorization: Bearer <api-key>`.
</Info>

Use **Lookups** for first-touch eligibility, **Refreshes** to re-evaluate an
existing lookup, and **Overrides** to correct a result. See **Reports** for
batch lookups and history.

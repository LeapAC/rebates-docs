Check whether a customer qualifies for utility rebates, and get a Connect URL you can hand to the customer to apply. Lookups run against the Leap API Gateway.

## Base URL

| Environment | URL |
| ----------- | --- |
| Production  | `https://api.leap.energy` |
| Staging     | `https://api.staging.leap.energy` |

## Authentication

Send your Leap API key as a **Bearer token** in the `Authorization` header:

```http
Authorization: Bearer <your-api-key>
```

## Endpoints

- **Look up incentives** — first-touch eligibility for a new customer.
- **Refresh incentives** — re-evaluate a customer you've already looked up, using their stored data.
- **Override incentives** — replace a customer's devices, then re-evaluate.

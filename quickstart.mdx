Leap Incentives lets you check a customer's rebate eligibility, hand them a Connect URL to apply, and submit supporting data on their behalf. Two APIs are involved:

- **Incentives Lookups** — `https://api.leap.energy`, authenticated with a **Bearer token**.
- **Applications** — `https://api.incentives.leap.energy/alpha`, authenticated with an **`x-api-key`** header.

## Setup

<Steps>
<Step title="Create your API keys">
  You'll use two keys — a **Bearer token** for the Incentives Lookups API and an **`x-api-key`** for the Applications API. Generate both in the [Incentives Portal](https://partner.incentives.leap.energy).
</Step>

<Step title="Get device IDs">
  In the [Incentives Portal](https://partner.incentives.leap.energy), map your product catalog to Leap's device catalog. Each mapping returns a `device_id` you pass in lookup requests.
</Step>

<Step title="Set up data preferences">
  Choose which application fields you'll provide on behalf of customers. Fields you claim are removed from the customer-facing form and become yours to supply. Configure these in the [Incentives Portal](https://partner.incentives.leap.energy).
</Step>
</Steps>

## Check eligibility and get a Connect URL

Send the customer's address, classification, and devices to the **Look up incentives** endpoint. Leap returns the total incentive, a per-program breakdown, and a `connect_url` the customer uses to apply.

### Request

```bash
curl -X POST "https://api.leap.energy/v1.1/global-connect/incentives/lookups" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "reference_id": "customer-123",
    "customer_classification": "RESIDENTIAL",
    "address": {
      "address_line_1": "456 Main St",
      "city": "Bend",
      "state": "OR",
      "zip_code": "97701"
    },
    "customer_devices": [
      { "device_id": "123", "partner_device_reference": "order-9001" }
    ]
  }'
```

### Response

```json
{
  "reference_id": "customer-123",
  "customer_classification": "RESIDENTIAL",
  "connect_url": "https://connect.incentives.leap.energy/your-company/refId/customer-123",
  "incentive_summary": {
    "upfront_amount": 0,
    "install_amount": 750,
    "ongoing_amount": 0
  },
  "utilities": {
    "primary": { "eiaid": "14354", "name": "PacifiCorp (Oregon)", "state": "OR" }
  },
  "program_details": [
    {
      "name": "Pacific Power – Oregon \"Charge at Home\" EV Charger Rebate",
      "device_category": "EV_CHARGER",
      "tiers": [
        { "tier_name": "Standard Rebate", "incentive_amount": 750 }
      ]
    }
  ],
  "customer_devices": [
    {
      "device_id": "123",
      "partner_device_reference": "order-9001",
      "customer_device_id": "88123"
    }
  ]
}
```

<Note>
  `connect_url` is empty when no eligible program can be processed yet. Check for a non-empty value before showing the link to a customer.
</Note>

<Tip>
  Returning customer? Use [Refresh incentives](/api-reference/incentives-lookups/refresh-incentives) to re-evaluate with their stored data — no need to resend address and devices. Use [Override incentives](/api-reference/incentives-lookups/override-incentives) when their equipment has changed.
</Tip>

## Provide data on the customer's behalf

Once an application exists, supply the fields you claimed so the customer doesn't have to. Find the application, then update it.

### Find the application

```bash
curl -X GET "https://api.incentives.leap.energy/alpha/applications?refId=customer-123" \
  -H "x-api-key: leap_live_..."
```

Filter by `refId` (your reference ID) or `application_status`. See [Search applications](/api-reference/applications/search-applications) for the full response.

### Update the application

Send the data you're providing on behalf of the customer, using the application `id` from the search results.

```bash
curl -X PATCH "https://api.incentives.leap.energy/alpha/applications/123" \
  -H "x-api-key: leap_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "customer": {
      "first_name": "John",
      "last_name": "Doe",
      "email": "john.doe@example.com",
      "phone": "555-123-4567"
    },
    "customer_devices": [
      {
        "id": 45,
        "purchase_date": "2026-01-15",
        "installation_date": "2026-01-20",
        "purchase_price": 699.00,
        "contractor_name": "ABC Electric",
        "contractor_license": "EC-12345"
      }
    ]
  }'
```

<Note>
  Only include the fields you want to change — omitted fields keep their current values. Status and system identifiers (`id`, `customer_id`, `program_id`) are read-only and can't be modified here.
</Note>
